# Neura v2.6.0-rc.1

Updated: 2026-11-08
Channel: prerelease
Status: withheld draft. No published Mastra release

This release is experimental and not production-ready.
Human Away remains preview-only in historical source and is unavailable in the active CLI.
No npm package is published by this release.

## Release decision

The original Pi candidate has been superseded by an active Mastra development
application. `VERSION` and package metadata remain `2.6.0-rc.1`. This does not
select a Mastra release version or certify the old candidate. Keep the GitHub
entry a draft/prerelease. No new release tag or gated Mastra assets are established
by these notes. Latest published Neura remains the historical Pi-based `v2.5.1`.

Mastra EE scope and distribution approval remain unresolved. Local acceptance is
for development/testing with synthetic, non-sensitive data only. `verify:release`
must refuse distribution. Do not publish this draft or present a source-linked
checkout as a sealed runtime.

- Exact package-closure/license gates, frozen parity inventory and required
  Windows/portable CI contracts. These are not full legacy parity or release clearance.

## Limits and remaining gates

Work requires a configured Windows/WSL2/bubblewrap host for actual commands.
Dependency installation is manual. Learn-store creation requires native Windows. Browser progress returns through copied commands, and restored sources need reimport.
Subscription login/refresh/restart and entitlement coverage remain incomplete
despite recorded owner-reported working responses and live Work runs.

Plan, YOLO, Human Away, MCP/LSP, delegation, context compaction, durable effect
recovery and full trusted proof are unavailable. Quick detector receipts retain
`verified:false`. Git-ignored files without secret names can remain readable to
commands. Same-user application-path and plaintext-vault limits remain.

Release additionally needs reviewed Pi-free packaging, rights/notices,
clean-profile install/recovery evidence, independent review and required new-head
CI. See [releasing](../RELEASING.md) and [status](../STATUS.md).
[Parity](../PARITY_MATRIX.md) and [installer readiness](../INSTALLER_READINESS.md)
track unfinished implementation and setup.

## Evaluate and roll back

Follow the [current source quick start](../../README.md#quick-start-from-source)
and [development guide](../DEVELOPMENT.md). Install both locked graphs with
scripts disabled. Use disposable external projects and an optional explicitly
selected development launcher. Do not follow old Pi upgrade commands on current main.

Exit Neura before source/launcher changes. Select a known-good checkout or restore
only a verified installer-owned launcher backup. Preserve credentials, sessions,
approvals, memory, vaults, dirty worktrees and recovery backups. No automatic
rollback or live installation is performed by editing these notes.
