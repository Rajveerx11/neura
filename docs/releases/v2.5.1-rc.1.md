# Neura v2.5.1-rc.1

Release date: 2026-08-06  
Channel: private release candidate  
Stable release: blocked

## Purpose

Harden Plan filesystem containment and replace stale product documentation with
one verified release view.

## Included

- Routes Plan `read`, `grep`, `find`, and `ls` through the same deterministic
  action policy.
- Resolves Pi path aliases, canonical real paths, symlinks, junctions, and missing
  descendants before comparing with the active workspace.
- Adds positive and negative tests for direct outside paths, linked escapes,
  missing linked targets, `~`, `@`, and `file://` aliases.
- Preserves the logo-only launch.
- Adds architecture, development, security, contribution, release, status, plan
  index, and agent guidance.
- Adds a machine-readable version, documentation validator, and Windows CI.
- Makes live-install text comparison ignore line-ending-only drift.
- Removes unrelated ComfyUI dependency artifacts from the Neura source tree.

## Verification

```powershell
node scripts\verify-harness.mjs
node scripts\check-docs.mjs
powershell -File .\install.ps1 -Check
git diff --check
```

The first two checks and diff check must pass on the release commit. Live drift
check passes only after an intentional install of the same commit.

## Known blockers

- Unknown YOLO actions are not fully fail-closed.
- Proof does not gate autogit.
- Approval binding and redaction are incomplete.
- Gmail is not based on an explicit read-only allowlist.
- Runtime extension packages are not all pinned.
- Human Away has no OS sandbox or full adversarial replay.

See [../STATUS.md](../STATUS.md) for exact stable and Human Away gates.

## Upgrade

Do not install automatically. Review the diff, then run:

```powershell
powershell -File .\install.ps1
powershell -File .\install.ps1 -Check
```

## Rollback

Install the previous known-good commit with its `install.ps1`, then run its drift
check. Approval audit and personal memory remain outside the repository and are
not changed by rollback.
