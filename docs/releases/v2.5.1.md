# Neura v2.5.1

Release date: 2026-08-09
Channel: private stable

## Purpose

Close the release-candidate security and reproducibility gates without changing
Neura's logo-only launch or widening Plan policy.

## Included

- State-bound, one-use, expiring Human Away approval grants.
- Central secret redaction across model, audit, notice, Gmail, and sandbox
  presentation boundaries.
- Explicit Gmail read-only allowlist with confirmation/blocking for everything
  else outside YOLO.
- WSL2 bubblewrap execution as Human Away's only tool boundary: workspace-only
  writable mount, no host user paths, cleared environment, no network, and
  linked-workspace rejection.
- Adversarial regression and live sandbox replay.
- Pi `0.84.1` and exact runtime package pins, reviewed lifecycle behavior, locked
  development dependencies, TypeScript checking, npm vulnerability/signature
  audit, and complete Windows CI.
- All Plan-mode containment, Git inspection, publication lifecycle, and
  headless contract fixes developed after `2.5.1-rc.1`.

## Deliberate limits

- Human Away remains `PREVIEW`. Its sandbox requires Windows, WSL2, and
  `bubblewrap`; it fails closed without them and is not intended for unattended
  high-impact work.
- Plan containment remains application-level rather than an OS sandbox.
- YOLO intentionally has no Neura approvals or sandbox.
- Redaction is pattern-based defense in depth; raw credentials remain forbidden
  in prompts, commands, output, and repository files.
- Direct Plan `web_fetch` stays disabled because its delegated backend does not
  expose DNS, connection-IP, or redirect-hop evidence required for SSRF policy.

## Verification

```powershell
npm ci --ignore-scripts
npm run typecheck
npm audit --audit-level=high
npm audit signatures
node scripts\verify-harness.mjs
node scripts\verify-sandbox.mjs
node scripts\check-docs.mjs
git diff --check
powershell -File .\install.ps1 -Check
```

The stable tag is created only after the release commit passes GitHub Windows
CI and the intentionally synced live harness passes the drift check.

## Upgrade

1. Install Pi `0.84.1`.
2. Run `powershell -File .\install.ps1`.
3. Run `pi update --extensions --approve` so exact runtime extension pins are applied.
4. Run the verification commands above.

`install.ps1` preserves unrelated model/provider choices, keybindings, skills,
and local-only files while merging Neura's exact runtime package pins.

## Rollback

Install the previous known-good commit and its pinned Pi version, run that
commit's `install.ps1`, then run its drift check. Approval audit and personal
memory stay outside the repository. Do not rewrite the `v2.5.1` tag; publish a
fixed patch release.
