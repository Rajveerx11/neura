## Do this now

1. Start a **new** Neura thread in T3. The failed thread's process still runs the old code.
2. Switch it to Learn and ask it to open `Probability_PRP/Tutorial 1.pdf`.
3. Run `/learn accept-plan` when the path appears.
4. Run `git push origin main` when you want the fix on GitHub. It is committed locally, and `main` is protected, so a direct push needs your admin bypass.
