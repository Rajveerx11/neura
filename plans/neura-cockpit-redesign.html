Lifecycle model

Four phases. One continuous session.

Launch is preflight. Contextual surfaces appear only when a decision, failure, or inspection requires them.

Brief

Turn a prompt into a visible contract.

  • Outcome
  • Constraints
  • Proof
  • Allowed scope
02

Work

Show one active step without dashboard noise.

  • Current operation
  • Milestones
  • Interrupt hint
  • Agent status
03

Proof

Separate running checks from final verdict.

  • Checkpoint
  • Harness tests
  • Proof gate
  • Evidence detail
04

Handoff

Close with scope, evidence, and next action.

  • What changed
  • Why
  • Do this now
  • Key takeaway
