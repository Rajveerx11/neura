<Callout id="limits" tone="warning">

**Not proven yet.** The live reviewer was the same model family. Neither run produced a must-fix finding, so the live fix loop is untested. The step-limit stop has fake-model tests only. Run 2 had one failed command, and my log did not record which one. Folders named `memory`, `sessions`, `private` or `secrets` stay blocked, which will hit some real projects.

</Callout>
