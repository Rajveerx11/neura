Pillar 04 · Human Governance

High-Density Approvals & Syntax Diffs

Transforming text-heavy policy pauses into high-fidelity decision prompts featuring syntax-highlighted diffs, path-scoped approvals, and feedback re-injection on denial.

BEFORE · Current v2.5.1 Action Request Monolithic Text Lines & Single-Use Retry
NEURA / AGENT ACTION REQUEST 1
────────────────────────────────────────────────────────────────────────

◇ Neura paused at a policy boundary req_8842

TASK update authentication token rotation

INTENT complete the active task within policy

ACTION write src/auth/token-manager.ts

EVIDENCE isolated Reviewer · high risk

BOUNDARY protected path requires human approval

FALLBACK submit proposed patch to plans/ for review

Friction & Blindspots

  • Blind Approval: Shows only the file path (write src/auth/token-manager.ts). The developer has no idea what code is actually changing without opening a second terminal.
  • Binary Grant Scope: Either approve once for 120 seconds, or abort. If an agent needs to touch 5 related auth files, the user gets interrupted 5 separate times.
  • Silent Rejection: Denying with n aborts the action, but doesn't pass structured corrective guidance back to the agent.

Friction & Blindspots

  • Log Hunting: Failures dump a file path to an obscure log file instead of showing the exact failure line inline.
  • Blind Time-Travel: Invoking /undo rolls back changes blindly. The developer doesn't see what commits or files will be destroyed.
  • No Partial Reversion: It's all-or-nothing rollback without cherry-picking.

Pillar 07 · Speed of Thought

Command Palette & Keyboard HUD

Eliminating hidden keybinding friction by providing an instant fuzzy command palette (Ctrl+K) and context-aware single-key shortcut overlays (?).

BEFORE · Current Dispersed Shortcuts Hidden Memorization & Muscle-Memory Clashes

CURRENT KEYBOARD DISCOVERY:

No built-in cheatsheet HUD or command palette.

Shortcuts scattered across extensions:

  • Shift+Tab · Cycle modes (no direct jump)
  • Ctrl+O · Expand thinking (undocumented in prompt)
  • Ctrl+X / Ctrl+Shift+X · Copy answer / code blocks
  • Ctrl+Shift+T · Toggle thinking level

Friction & Blindspots

  • High Cognitive Load: New engineers don't know what commands exist without reading the documentation or source files.
  • No Direct Mode Jump: Cycling through 5 modes with Shift+Tab requires 4 keystrokes to reach Learn mode from YOLO.
  • No Universal Command Launcher: Must memorize specific slash commands (/dash, /ship, /notices, /checkpoint).
