## Why

- **Conflict-by-hand, not overwrite:** the UI branch was 2 features behind main. A blind copy would have deleted the review workflow and your logo.
- **Separate CI PR:** the flake wasn't caused by the UI change. Keeping it separate made #146's review clean and #147 easy to revert.
- **Retry only on EBUSY:** a real bad signature or vulnerability still fails immediately. #147's own run hit EBUSY, retried, and passed.
