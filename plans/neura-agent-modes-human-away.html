Three modes. One safety boundary.

Add Plan, YOLO, and Human Away modes. Human Away uses a separate Headmaster agent to review eligible actions, while deterministic policy keeps secrets, broad destruction, security weakening, and untrusted external writes under human control.

Recommendation

Build Human Away as delegated review, not delegated power.

  • Headmaster replaces a human only for narrow, bounded, recoverable actions.
  • Sandbox and policy boundaries remain unchanged. Headmaster cannot add tools, paths, network access, or credentials.
  • Every approval covers one exact action, one workspace state, one use, and a short time window.
  • Suspicious or human-only actions are blocked immediately, logged safely, and surfaced when Rajveer returns.
  • Repeated denials stop the turn. Main agent must find a materially safer path, never a workaround.

Mode contract

Meaning stays precise.

Mode changes autonomy and approval routing. It never weakens fixed protection for secrets, protected paths, broad destructive actions, production systems, or policy files.

Policy model

Four outcomes, deny first.

Natural-language review is reserved for ambiguity. Known safe and known dangerous classes resolve deterministically, reducing cost, latency, and approval manipulation.

ALLOW

Routine, narrow, workspace-local, easy to reverse. No secrets, external writes, privilege change, security weakening, or meaningful data loss.

REVIEW

Bounded side effect needing context. Headmaster may approve once after read-only preflight proves target and recovery.

HUMAN

Sensitive data, protected configuration, production/shared systems, significant deletion, external publication, or unclear authorization.

DENY

Credential exfiltration, broad root/home deletion, disk format, guardrail removal, audit tampering, persistent broad security weakening.

Why hard rules stay outside Headmaster

OWASP recommends complete mediation in downstream enforcement rather than relying on an LLM to decide authorization. It also warns that decision/approval manipulation is itself an agent risk. NIST’s 2026 concept paper highlights least privilege, delegated authority, agent identity, audit, and binding actions back to human authorization. OWASP LLM06 · NIST

Return sequence

session_start restores queue. First input with source === "interactive" shows widget and notification. User message still proceeds unless review UI is opened.

Approve means retry, not replay

Neura never executes a stale queued command directly. Human approval creates a one-shot token and asks main agent to retry. Policy re-resolves paths and workspace state before matching.

No retry gaming

Three consecutive Headmaster denials or ten denials within fifty reviews abort current turn. Denial reason tells agent to choose a materially safer path. This mirrors Codex’s current Auto-review circuit breaker. Source

Primary-source research · cutoff 02 Aug 2026

Evidence behind design.

Core pattern is now proven by both OpenAI and Anthropic: separate reviewer/classifier, fixed sandbox/policy boundary, narrow approvals, denial feedback, circuit breakers, and durable audit. Neither vendor claims model review is a security guarantee.

OPENAI · 30 APR 2026 · ALIGNMENT RESEARCHAuto-review of agent actions without synchronous human oversight

Separate reviewer evaluates boundary-crossing actions using intent, environment, security policy, and impact. Reports about 200× fewer human stops in its internal snapshot, while explicitly warning reviewer can be misled and is not deterministic security.

OPENAI · CURRENT CODEX DOCSCodex Auto-review

Reviewer swap does not expand writable roots, network, protected paths, or sandbox. Shows compact evidence, structured denial behavior, exact retry override, and current 3-consecutive/10-in-50 denial breaker.

OPENAI · 08 MAY 2026 · SECURITYRunning Codex safely at OpenAI

Describes bounded environment, low-risk frictionless actions, explicit high-risk review, rules, Auto-review, agent-aware OpenTelemetry, and security triage using user intent, tool actions, approvals, and results.

OPENAI · CURRENT OPEN SOURCECodex guardian policy template

Useful taxonomy: evidence as untrusted, authorization scoring, low/medium/high/critical risk, read-only investigation, conservative missing-context behavior, and outcome thresholds after risk/authorization.

ANTHROPIC · CURRENT CLAUDE CODE DOCSClaude Code permission modes

Plan is read-only; Auto uses a separate classifier; protected paths remain protected except bypass mode. Auto blocks scope escalation, untrusted infrastructure, production actions, destructive pre-session files, force push, and direct main push.

ANTHROPIC · CURRENT CLAUDE CODE DOCSClaude Code keyboard shortcuts

Confirms mode cycling uses Shift+Tab. Neura v1 now matches it and retains /mode as the explicit fallback.

OWASP · AGENT SECURITYAI Agent Security Cheat Sheet

Calls out tool abuse, data exfiltration, excessive autonomy, high-impact actions, decision/approval manipulation, cascading multi-agent failures, and monitoring needs.

OWASP · LLM06:2025Excessive Agency

Recommends minimal functionality/permissions/autonomy, human approval for high-impact actions, and complete mediation enforced downstream rather than by LLM judgment alone.

NIST NCCOE · FEB 2026 · CONCEPT PAPERSoftware and AI Agent Identity and Authorization

Frames least privilege, dynamically scoped authorization, proof of authority, intent, delegation, binding human and agent identities, auditing, tamper resistance, non-repudiation, and prompt-injection mitigation.

Evidence limits

OpenAI’s reported approval and recall numbers are internal/synthetic deployment results, not a guarantee for Neura. Headmaster model, prompt, workspace mix, Windows execution path, and tool ecosystem differ. Cheapest uncertainty reduction: replay a sanitized corpus of Neura’s real approval prompts, then adversarially augment it before unlock.
