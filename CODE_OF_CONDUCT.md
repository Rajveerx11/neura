# Code of conduct

## Our standard

Neura community is committed to a respectful, harassment-free environment.
Be constructive, patient, technically honest, and mindful that contributors
have different backgrounds and levels of experience.

Acceptable behavior includes:

- discussing ideas and evidence without attacking people;
- giving actionable, specific feedback;
- acknowledging mistakes and correcting them;
- respecting privacy, boundaries, and project security rules;
- prioritizing community safety over winning an argument.

Unacceptable behavior includes:

- harassment, threats, discrimination, or sexualized attention;
- insults, trolling, intimidation, or sustained disruption;
- publishing private information without explicit permission;
- posting credentials, exploit details, or private user data publicly;
- impersonation or deliberate misrepresentation of project safety.

## Scope

This policy applies in repository issues, pull requests, reviews, discussions,
release channels, and public spaces where someone represents Neura.

## Reporting

Report conduct concerns privately to repository maintainer through GitHub.
Security-sensitive reports must use a private GitHub security advisory under
repository Security tab. Do not include credentials or unnecessary personal
data.

Maintainer will review reports, preserve confidentiality where possible, and
may remove content, issue a warning, restrict participation, or ban a
participant. Conflicts involving maintainer should be reported through GitHub's
abuse-reporting process.

## Enforcement

Responses consider severity, repetition, context, impact, and willingness to
repair harm. Retaliation against someone making a good-faith report is itself a
violation.
