# Neura introduction

## LinkedIn post

AI can write code.
Trust starts after the code is written.

I've been building Neura, my personal engineering agent on top of pi.

I didn't want another chat wrapper. I wanted an agent I could give real repository access to without giving up control.

So Neura:

• remembers decisions across sessions
• connects skills, MCP tools, LSP diagnostics, and local or cloud models
• checkpoints the worktree before every run
• requires approval before destructive commands and secret-file access
• verifies changed work automatically, with /ship for full tests and a signed audit verdict

The model still does the reasoning.

Neura supplies the engineering system around it: context, guardrails, recovery, and proof.

The goal isn't more autonomy at any cost.
It's autonomy you can inspect, reverse, and trust.

What would you need before letting an AI agent work inside your main repository?
